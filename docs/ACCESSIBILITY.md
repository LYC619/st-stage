# 键盘操作与无障碍支持

## 已实现

- 用 Tab 定位手机图标，Enter 或空格打开；焦点进入 App 栅格。App 图标、返回、收起和共用按钮支持 Enter/空格。
- 打开 App 后焦点进入有名称的内容区，再按 Tab 到第一个控件。App 内 Esc 返回主屏并定位原 App 图标；主屏 Esc 收起到手机图标。
- 设置触发同一 App 重挂载时，尽量恢复同位置、同类型控件的焦点及文本选区；结构不再匹配时回到 App 内容区。
- `ctx.openModal` 共用弹窗带有 dialog/aria-modal 语义，Tab/Shift+Tab 在可用控件间循环。隐藏、禁用和折叠内容不进入顺序；原生 radio 分组和 contenteditable 支持独立浏览器回归。
- 嵌套共用弹窗只让最上层处理 Esc。关闭后恢复原控件；若 App 已重新挂载，则保留平台返回时设置的内容区焦点。
- 共用文本框有程序关联的标签；滑块有可读数值；帮助按钮有展开状态、关联说明和键盘操作。图库 App 缺少 API key 的反馈通过状态区域保留。
- 图库管理、标签管理、上传预览、图片预览和存储迁移弹窗使用同一套焦点生命周期；嵌套时最上层接收键盘，显示层级随之上移。图片预览的左右键不会穿透到下层。
- 图包与立绘卡支持方向键、Home/End 导航和 Enter/空格打开；卡内排序按钮独立响应。启用列表保存后按图包 ID 恢复焦点，同名图包不会混淆；返回列表时定位原图包。
- 下拉面板关联触发按钮的展开状态；Esc 先关面板并返回触发按钮。预览操作保留名称与焦点，说明用状态区域播报。旧浏览器的复制降级路径在当前弹窗内完成选区操作，再恢复焦点。
- MVU／新变量的变量叶子可用 Enter／空格编辑，字段以变量路径命名，取消后返回原叶子。异步保存只在用户仍停留在原编辑区域时恢复焦点，不会打断已转去操作其他控件的用户。
- 变量设计器接入模态焦点管理；类型和输出格式切换后保留对应控件焦点。模板、保存和删除等原生按钮只响应一次 Enter。
- 旧 API 管理弹窗支持初始焦点、Tab 循环、Escape 和返回焦点。新原生档案按钮有选中/禁用状态，角色推荐有独立标签；分支预览、保存选择和填草稿是不同控件。
- 变量速查浮窗是具名非模态 region；Enter／空格或辅助点击打开，焦点进入收起按钮，Esc／收起返回浮窗按钮。Tab 可离开，拖动不会触发重复开关。
- 导出分类使用 tablist／tab／tabpanel，左右方向键和 Home／End 切换；选择框和聊天展开项有名称。重绘按资源身份恢复当前控件，异步完成不抢走已移到其他位置的焦点。读取、选择计数和压缩进度使用常驻状态区域。
- 聊天图片保存提示支持中英文和动态播报；加载失败的楼层图片可用 Tab 定位，Enter／空格重试，加载成功后退出交互顺序。
- 微信设置的两个滑块、位置选择和 API 字段有可见关联标签，固定浅色界面的表单文字不再继承酒馆深色主题文字。发送、状态标签和红包文字的已检出对比度问题已修复。
- 微信红包和照片使用具名模态框：打开时进入、Tab 循环、Esc 关闭并返回来源。照片可用 Enter／空格打开；同一会话的状态刷新重建消息后，关闭仍回到对应照片。表情抽屉显示展开状态，键盘可选择两组表情，Esc／选择后返回表情按钮；切换聊天关闭旧浮层。
- 图库卡片的朗读名称来自可见内容，打开／选择说明保留在提示中；启用包按钮的名称包含可见按钮文字与目标角色，便于按可见名称定位。

手机作为具名 region，不强制启用读屏软件的 application 模式。Tab 可以离开非模态手机区域；模态弹窗限制焦点。

## 尚未完成

其他非核心工具内部仍需补全翻译，完整的读屏和键盘验收仍须按实际使用路径进行。隔离 ST 1.18.0、酒馆助手 4.11.3 与原始 MVU `74f930e` 已通过真实读写、事件、Variables 编辑及重载检查。旧读取迟到和评估中管理权变更也使用真实 MVU 数据补验，但读取交付时机、通知和模型响应为显式控制条件；不代表其他版本兼容或自然生产竞态验收。

本轮 `1226` 在真实隔离宿主中回跑桌面英文和 320×667 中文共 38 次 axe WCAG A/AA 规则扫描；`1309` 新增功能在桌面中文、320px 中文和390px 英文另有 9 次扫描。合计 47 次已检出违规项为 0；38 次既有扫描的相关代码此后未变，仅旧 API 兼容说明文案更新。渐变背景、纯符号按钮、空输入框和按需生成的弹出面板仍有 `incomplete` 项（81 次规则记录，含重复界面），不能把它们视作自动通过。

这不是 WCAG AA 合规声明。实体手机、操作系统输入法、真人读屏、WAVE 和完整全界面对比度验收尚未完成。浏览器模拟与 DOM/ARIA 断言不能代替这些检查。详见 [本批证据](maintenance/history/2026-11-05-character-play-mobile.md)。

## 开发与回归

`core/dialog-focus.ts` 管理最上层焦点。调用方在 DOM 插入后创建管理器，内容构建后调用 `focusInitial()`；关闭时先 `dispose()`，移除 DOM、恢复来源 App，再 `restoreFocus()`。生命周期函数必须保持幂等，不能在销毁后继续触发界面回调。

如果外层 backdrop 建立定位层级，传入 `layer: backdrop`，确保新弹窗出现在旧弹窗之上；销毁时恢复原内联层级。来源控件可能被打开钩子移除时，应提前捕获并传入 `opener`。不要把用于复制的临时文本框放在活动模态框之外。

```powershell
node scripts/verify-dialog-browser.mjs
node scripts/verify-maintenance-browser.mjs
# 仅允许使用隔离数据的回环 ST 实例
node scripts/verify-i18n-browser.mjs --url http://127.0.0.1:18769 --isolated-data
node scripts/verify-gallery-browser.mjs --url http://127.0.0.1:18769 --isolated-data
node scripts/verify-variables-browser.mjs --url http://127.0.0.1:18769 --isolated-data
node scripts/verify-export-browser.mjs --url http://127.0.0.1:18769 --isolated-data
node scripts/verify-accessibility-browser.mjs --url http://127.0.0.1:18769 --isolated-data
```

前两项使用合成数据与生产模块；其余运行真实 ST 宿主和构建产物。图库脚本会替换隔离测试用户的图包；变量脚本创建测试角色、聊天并重设新变量配置；导出脚本创建测试角色／聊天／世界书／预设，替换测试正则并核对实际下载 ZIP。无障碍脚本重设测试 App 数据，使用内置表情及合成照片，并保存扫描、键盘断言、截图和无法自动判断的项目。MVU 脚本另用独立测试用户，记录第三方版本与构建哈希。均不用于日常 ST 数据。导出验收不等于 ZIP 导入验收。证据保存在忽略的 `test-results/`，当前未提交构建的结果及限制由 `docs/maintenance/CURRENT.md` 记录。
