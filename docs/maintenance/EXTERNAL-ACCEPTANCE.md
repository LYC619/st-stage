## 实体手机步骤

1. 记录设备型号、OS、浏览器、输入法、构建号与横竖屏 CSS 视口宽度。
2. 在微信用中文拼音选词，确认不误发送；正常发送后仍可输入。
3. 软键盘弹出后确认输入框、发送按钮、最近消息可见；收起后无永久偏移和横向溢出。
4. 从图库逐层打开、关闭管理器及弹窗，检查返回 App 和焦点；补键盘路径。
5. 发送后立即切角色或聊天，确认旧结果不会写入新会话；重载后各自保存。
6. 记录结果与重现步骤，截图使用合成数据。

## 执行条件

使用专用验收连接、可丢弃角色和测试账户。禁止读取或迁移日常 ST 的设置与密钥。
MVU 验收记录宿主、助手与 MVU 版本、来源哈希及控制时序；缺失条件留在本表。
