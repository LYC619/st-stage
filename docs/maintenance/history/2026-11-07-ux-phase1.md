## 实现

- 聊天照片使用最大 72% / 220px、最小 120px 的媒体容器，图片保持自然宽高比和最大 220px 高度；群聊作者容器只约束一次百分比。消息表情保留 110px 小尺寸，抽屉表情保留 46px，均使用 `contain`。
- `image-media.ts` 统一聊天照片、消息表情、灯箱和朋友圈配图的失败提示、警告标记和显式键盘重试。重试不改素材 URL 或历史快照；可访问名称包含可见文案。聊天媒体按消息复用节点，回复刷新保留错误状态和焦点。
- 朋友圈采用默认折叠的发布区，保留作者选择、生成/取消和提示词编辑，Feed 独立滚动。初次打开仍渲染列表；发布成功仅 `prepend` 新卡，删除超出原有 200 条上限的末尾卡。保存失败回滚，不插入新卡。点赞继续局部更新。
- 发布前记录可见旧卡及其相对 Feed 偏移，处理完成状态后恢复该位置；位于顶部时保持顶部。配图预留 220px 高度，错误、重试及延迟加载不会改变卡片高度。旧卡节点、点赞和焦点保留。
- 手机壳返回/关闭用透明 `::after` 提供 44×44px 目标，保留原 30×26px 按钮及字号。热区向上扩展，手机屏幕继续裁剪内容，外壳允许透明热区越过圆角边缘；避免横屏热区截获微信内部导航按钮。

涉及源码：`core/phone-shell.css`、微信 `view.ts` / `wechat-app.ts` / `social-ui.ts` / 新增 `image-media.ts`。配套更新回归测试、真实 ST 浏览器验证器及三通道生成产物。未实现输入条整合、删除确认、群头像改版、手机宽度变化或图库瀑布流。
