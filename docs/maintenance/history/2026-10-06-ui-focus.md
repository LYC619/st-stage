Code/build: `d55fd4c8ff6f9c3626ff8ae959e7596029ed7fc5` on `codex/i18n-acceptance`. Build `0.9.0+202610062032`. Work began October 1 and resumed October 6 after interrupted sessions. This is one completed batch of the active autonomous goal; no merge, push or independent release was performed.

## Delivered behavior

- Sprite and Gallery App names, descriptions, settings, confirmation text, feedback and Help are translated. Locale dictionaries grow from 51 to 116 matching keys. Persisted IDs/options, user pack names, prompts and syntax such as `[立绘:xxx]` and `{清单}` are preserved.
- Shared App modal semantics and focus lifecycle now support dynamic Tab stops, nested Escape ordering, focus return, synchronous self-close and disposal. Native radio grouping and implicit contenteditable are covered.
- Phone launcher, App entry, home/back and collapse work by keyboard. The phone is a named region rather than application mode. Settings-driven remounts preserve matching control focus/selection; native labels and aria-labelledby text prevent focus moving into a newly inserted different field.
- Widgets expose labels and Help relationships, slider values and focus indication. Real ST exposed a select-name issue from wrapping all options in a label; explicit aria-labelledby fixes it. Rejecting Gallery auto-upload without an API key no longer saves unchanged settings/remounts away the message.
- New CI completeness script checks both dictionaries, interpolation names, static source references, Chinese fallbacks and parameter-object keys. Unverifiable dynamic fallback/parameter expressions fail instead of silently bypassing checks.
