## 实现

- 输入栏依次为语音切换、表情、礼物、输入区域和发送。语音模式使用紧凑 🎙️/⌨️ 按钮；支持识别时显示「点击录音」，开始后可点击结束。识别文字只进入可编辑草稿，不自动发送；显式发送后继续使用既有语音气泡和 TTS 路径，不保存音频文件。
- `voice-input.ts` 管理识别会话，通过 `bridge.ts` 检测安全上下文及标准/前缀识别接口。无支持、权限拒绝、无语音、网络错误、启动失败或 60 秒超时均保留文字入口和原草稿。重新录音追加草稿；切换模式/会话、打开对话框/表情面板或卸载时中止识别，并忽略迟到回调。真实浏览器发现并修复结束录音时隐藏按钮导致的焦点丢失：先记录焦点归属，再切换并聚焦草稿。
- `#wt-mention` 保留原生下拉和键盘入口，仅在群聊中显示为输入栏上方的紧凑胶囊。选择成员会中止录音、恢复文字模式、插入既有稳定身份 token 并聚焦输入框。单聊隐藏这行。
- `deletePacksWithChoice` 改为单次自定义确认面板，显示图包数量、名称及绑定影响，附默认未勾选的「同时删除本地服务器上的独占图片源文件（共 N 张）」。沿用子对话框焦点管理、Tab 约束、Escape 和取消焦点恢复，未确认关闭不删除。删除中阻止重复操作；目标被修改时拒绝使用旧选择，删除每张图片前重新检查共享引用。部分文件失败仍保留图包供重试，成功时基于最新设置移除记录，保留并发的其他设置改动。新增文案同步中英文 locale。
- 群头像保留 44px 外框：2–4 人用 2×2、18px 子头像；5–9 人用 3×3、13px 子头像，超过九人仍只展示九格，不改变群成员身份或标题。
- 手机壳 JS 使用 `targetMaxW = vw >= 768 ? 380 : 320` 与 `Math.min(targetMaxW, vw - 16)`，CSS 提供相同断点的回退。320px 视口收缩至 304px，280px 收缩至 264px；继续使用既有视觉视口缩放、平移与高度钳位。

涉及源码：`core/phone-shell.ts/.css`、微信 `view.ts` / `wechat-app.ts` / `social-ui.ts` / `groups.ts` / `bridge.ts` / 新增 `voice-input.ts`、`sprite-manager/list.ts`、扩展样式及 locale。对应单测、真实 ST 验证器、微信使用说明和三通道生成产物同步更新。详情标签化、图库瀑布流、@ 内联推荐和拖拽调宽未纳入本轮。
