## 11 月 4 日：修复可靠性问题，补齐真实宿主验收

- **图片存储与迁移**：修复原生 `fetch` 调用上下文导致的 `Illegal invocation`；验证图片去重上传、字节回读、保存重载、迁移回执和选择性恢复。导入取消或失败时不留下半成品图包。
- **分享与 Renderer**：分享码保留有效封面标记和图片顺序；Renderer 恢复原始节点及监听，修复普通比较符号被误判为 HTML 的情况。
- **导出与恢复**：对无法唯一识别的角色拒绝猜测，精确匹配世界书；取消／失败时停止后续任务和迟到下载，保留选择便于重试。实际下载 ZIP 并通过宿主 API 按类别恢复角色、聊天、世界书、预设和正则设置；未实现原生整包或完整账户恢复。
- **管家与发布基础**：损坏恢复状态有持久提示，修复无效二分排查循环；增加候选清单、文件哈希校验、备份同步和异常回滚工具。
- **角色入口与集成验证**：增加首页角色概览，集中呈现图包、变量和相关配置入口；在隔离 SillyTavern 中验证存储、分享、导出、变量与真实 MVU 集成。首页概览随后调整为 App 网格下方、默认折叠。

依据：[路线 A](2026-11-04-roadmap-a.md)、[发布前收尾](2026-11-04-release-readiness.md)、[真实 MVU](2026-11-04-real-mvu-acceptance.md)。

## 11 月 5 日：角色配置、手机适配与独立微信

- **角色配置与模板**：支持全局默认、角色专用覆盖及恢复继承；通过稳定角色身份隔离同名卡。场景模板可命名保存、预览和导入导出，不携带密钥或聊天记录。
- **原生 API 与分支体验**：API 管理入口复用原生 Connection Manager 的稳定档案 ID，角色推荐保存档案引用；应用档案不等于证明真实模型连通。Renderer 支持分支内容预览、选择持久化及填入草稿，由用户确认发送，不自动生成额外分支或改写主聊天。
- **手机适配**：修复 API 管理器高度为零、弹层偏移及宿主变换／视口滚动导致的定位问题；手机壳与管理弹窗统一视口定位，并补齐焦点、Escape 和键盘操作。当轮完成 136 项布局断言。
- **独立微信会话**：先显示联系人列表，入口自动加入当前宿主角色；主聊天为 A 时可独立与微信 B 对话，不读取 A 的主聊天或 MVU。每个会话独立保存草稿、未读、历史和请求状态，并保留旧历史迁移。
- **微信配置与素材**：聊天／状态／输出提示词可编辑、预览及恢复默认；一次回复同时产生消息和角色状态，取消旧的第二次数值评估及钱包／生活费流程。图库图片可作为表情或照片，消息保存素材快照；红包／礼物支持任意虚构内容与附言，不涉及实际支付。

这一批 A–G 成果于当晚完成双仓发布，随后补发“进入微信自动加入当前角色”的修复。

依据：[角色与手机适配](2026-11-05-character-play-mobile.md)、[独立微信](2026-11-05-wechat-experience.md)、[当前角色入口修复](2026-11-05-wechat-current-contact.md)、[11 月 5 日发布](2026-11-05-publication.md)。

## 11 月 6—7 日：社交功能、模块整理、性能与发布自动化

- **立绘管理模块拆分**：将大入口整理为列表、详情、灯箱、上传、设置、资源、控件与生命周期模块，使用显式共享上下文，便于维护和回归。
- **群聊与朋友圈**：群成员使用独立人设和状态；支持按稳定身份、姓名或全群进行 @。朋友圈可基于角色与近期状态生成动态，支持配图、点赞、持久化及最多 200 条记录。
- **语音与请求恢复**：语音消息保留可读文本，用户显式请求 TTS 播放；失败、取消、60 秒超时和重试有恢复入口，防止玩家消息重复及迟到结果污染状态。
- **复审修复**：统一群聊与动态请求快照；修复成员状态时间戳、`@allison` 被误识别为全群、TTS 提示与超时、语音展开／焦点丢失、等待压缩模块时取消无效等问题。补齐同次回复中的合法心情值处理，以及提交遗漏分块／翻译文件的发布门禁。
- **构建性能**：开启压缩并将 JSZip 改为按需加载，导出时才请求压缩模块；加入主包大小上限与分块完整性检查。最终 UX 版主包为 **625,909 字节**，压缩模块另行加载。
- **双仓发布自动化**：`pnpm release:full` 串起测试、固定候选、哈希校验、备份、同步、提交和正常推送；支持按回执恢复，推送后核对远端提交。准备候选与正式发布有明确阶段，不强推、不重写安装仓库历史。

这一轮“五阶段功能演进”与下面的“UX Step 1–5”是两批工作，均已发布。

依据：[五阶段演进](2026-11-07-five-phase-evolution.md)、[复审修复](2026-11-07-five-phase-repairs.md)、[上午发布](2026-11-07-publication.md)。
