# 设计走查 checklist（移动 + PC，人工执行）

发版前或大改 UI 后，人工过一遍本清单。**不做像素 diff CI**——发现的问题记到「问题记录」表，喂给稳定化阶段逐个修。每次走查花 20–30 分钟即可，优先移动端（问题密度更高）。

## 环境（三套，至少跑前两套）

- [ ] **真 ST · PC**：桌面浏览器打开 SillyTavern，扩展设置面板确认版本号是本次构建
- [ ] **真 ST · 手机**：真机（或 DevTools 375×667 视口 + 触摸模拟）打开 SillyTavern
- [ ] **Web 模拟器**：`pnpm dev` 起 3000 端口过一遍双端；`pnpm test:mobile` 移动 E2E 兜底

## 手机页设计三原则（每个 App 逐一对照）

1. **手机页只放三样**：开关 + 状态展示 + 入口。复杂编辑一律走全屏弹窗（打开前自动收起手机、关闭后回到原 App）
2. **图片集合用封面卡片墙**，不用纯文字列表——交互模式错配比视觉瑕疵更伤体验
3. **说明文字用 ⓘ**：桌面悬浮显示、手机点开显示；正文区不堆长段说明

## 通用走查项（跨 App）

- [ ] 触控目标 ≥ 44×44px（按钮/开关/行项/返回键/Home 键/✕）
- [ ] 320–375px 宽度下无横向滚动条、无文字截断成「…」丢关键信息
- [ ] 手机壳完整钳入视口：旋转屏幕、软键盘弹出、地址栏伸缩后不出界
- [ ] 拖动 📱 图标到四角再展开，壳不越界；tap 展开不触发底下元素幽灵点击
- [ ] 暗色背景下文字对比可读（so-app-desc 灰字在真机上检查一次）
- [ ] 长列表滚动流畅；折叠分区（foldSection）标题常显、默认折叠不漏分区
- [ ] 空态有话说（未绑定/无数据时给出下一步入口，不留白屏）
- [ ] 错误态有话说（mount 失败占位页、网络失败 toast/提示，不静默）
- [ ] PC 键盘可达：Tab 聚焦 + Enter/Space 触发（返回键/Home 键/App 图标已支持，新增交互对齐）
- [ ] 数字输入框失焦后值被夹回合法区间且回显

## 弹窗类（图库管理 / 变量设计 / API 管理）

- [ ] 打开前手机自动收起，弹窗不被手机壳遮挡
- [ ] 关闭后回到来源 App（图库→gallery、变量设计→newvar、API→api）
- [ ] 手机端弹窗全屏、内部滚动正常、软键盘不顶飞输入区
- [ ] Esc / ✕ / 点遮罩三种关闭路径一致

## 各 App 要点

- [ ] **Home 屏**：图标栅格排序稳定（内置 order 1–20），独立 App 注册后即时出现
- [ ] **立绘**：预算/数量/深度改完，「预计注入 N 字符」提示随之更新；超预算时提示截取前长度
- [ ] **图库**：卡片墙封面加载（lazy）、上传/替换后缩略图刷新、lightbox 方向键与半区点击
- [ ] **管家**：一键性能模式改前快照可还原；ⓘ 说明桌面悬浮/手机点开都可读
- [ ] **MVU / 新变量**：变量树折叠展开顺滑、delta 徽标可见、编辑值后不跳滚动位置
- [ ] **API**：站点行点击即切换且在线状态随真事件变化；Key 不在界面明文回显

## 大图包专项（用 300+ 张的包过一遍）

- [ ] 图库管理弹窗打开不卡死；滚动时图片按需加载（loading=lazy 生效）
- [ ] 切角色/切聊天时无整包预载（激活预载 ≤4 张、命中序列 ≤10 张）
- [ ] 设置 Prompt 预算（如 2000）后：立绘 App 显示截取提示，AI 仍能正常出图
- [ ] settings 保存不超时（ST 端 saveSettings 无报错）
