# 手机 API 入口

百工优先列出 SillyTavern 原生 Connection Manager 的连接档案。连接地址、密钥、模型和预设继续在酒馆 API 面板管理；百工读取档案显示信息，点击后让原生连接管理器应用档案。无需再抄一份配置。

「当前角色推荐」只保存角色头像身份与原生档案 ID 的关联，不复制密钥，不自动切换。更换聊天或同名角色时，推荐跟随实际角色卡。原生档案改名后引用仍有效；删除后显示失效，可选「不指定推荐连接」解除。头像身份变更后需重新关联。

「已选档案」表示原生管理器当前选中它。上方显示酒馆报告的状态；「酒馆允许发送」不代表真实模型请求成功：例如自定义 API 即使状态检查失败，ST 也可能显示「已跳过状态检查」并允许发送。百工会保留这个原生状态文本。若未连接或状态检查被跳过，在原生面板检查地址、模型和凭据，使用专用连接实测。超时表示未收到完成事件，宿主可能仍在处理，不等于回滚。离开手机页不会撤销已发起的原生操作，回来后会读取当前状态。

「旧百工档案与管理」折叠区保留已有档案及旧管理页。旧档案的存储与切换方式沿用原行为；没有静默删除、迁移或回读密钥。建议新连接在原生面板建档。Connection Manager 禁用或未就绪时会说明，旧入口仍可打开。

微信自身的回复管线仍使用微信设置中的 Chat Completions 端点；本页切换的是 SillyTavern 主聊天连接，两者不会自动同步。
