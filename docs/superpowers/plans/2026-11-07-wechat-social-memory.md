# 微信记忆与社交体验升级

用户授权实施主聊天/世界书记忆、微信/通讯录/朋友圈三页导航、自动动态及仅玩家可见动态。基线 `0bf8ae2`，产品基线 `02c8da4`，发布版本 `0.9.0+202611071934`。本批开发和验证；先前文档推送授权不作为本批新产品发布授权。

## 调查与决定

- 请求链路使用独立 `conversationScope`，未调用宿主近期消息提取；新建数据硬编码条数 0，世界书未接入。须修复完整请求链路。
- 参考 WeiMeng `37e4c0609fb353025578df69434ac9a6d756bf13`，MIT，重点为 `src/variable-updater.js` 的纯文本近期对话与 `src/moments-updater.js` 的剧情触发、互斥及切换聊天校验。参考版本未发现可直接移植的独立世界书读取器，世界书以本地 ST 实际接口为准。
- 复用既有请求、联系人、群聊、图片和增量 Feed 模块。保留独立微信聊天记录与角色身份，主线作为带来源的背景，不把其他角色经历冒认为当前联系人的经历。
- 默认最近 12 条主聊天、启用相关世界书；保留用户可见关闭/条数设置。旧版隐式 0 做一次迁移，之后用户明确的 0 保留。
- 世界书取角色绑定、全局启用及当前聊天绑定，匹配常驻/关键词条目，禁用条目排除，限制内容预算。读取失败显示反馈，不伪称加载成功。每轮冻结配置和背景，切换主聊天后取消尚未完成任务。
- 三主页面底部导航，聊天详情隐藏底栏；右上角 + 提供加好友/建群；通讯录含角色好友与群聊；朋友圈无模态遮罩，保留增量更新/阅读位置/键盘操作。
- 自动动态在进入微信和宿主新消息时触发，每批至多两位活跃角色，单任务互斥、剧情指纹去重、持久冷却、取消/超时/失败重试。后台只在已配置 AI 时请求；提供自动开关。私密动态是虚构社交可见性，不是数据加密。
