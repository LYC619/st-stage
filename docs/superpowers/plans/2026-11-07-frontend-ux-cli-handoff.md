1. 媒体自然比例、聊天/动态图片失败占位及重试、返回/关闭触控区域。优先修复能直接验证的问题。
2. 朋友圈内容优先布局、发布增量插入、滚动位置与焦点保持。点赞保持现有局部更新。
3. 语音切换并入输入条、保留 @ 选择器，删除图包合并为一次确认。顶部社交菜单作为同轮可选布局改进单独验收，不自动改为底部 Tab 架构。
4. 按成员数量适配群头像；大屏手机壳适度放宽，同时保留窄屏、横屏、缩放与视觉视口钳位。
