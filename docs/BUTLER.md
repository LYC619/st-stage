# 🧹 管家 App —— ST 性能管家使用说明

「管家」是 st-stage 内置手机里的一个 App，用来一键把 SillyTavern 调到更流畅的状态，尤其适合**手机端 / 低端机 / 长聊天**卡顿的场景。它改的都是 ST 自身的性能设置（`power_user`），并在改动前替你**保存一份原设置快照**，随时能一键还原——放心试。

> 打开方式：点聊天界面的 📱 图标 → Home 屏点「🧹 管家」。
> 每个选项右侧都有一个 ⓘ：桌面把鼠标**悬浮**上去看气泡说明，手机**点一下** ⓘ 展开说明。

---

## 一、一键性能模式

一个按钮把下面这些一次性调到省性能的组合：

| 项目 | 一键模式设成 |
| --- | --- |
| 背景模糊（No Blur） | 关模糊 |
| 减少动画 | 开 |
| 阴影 | 关 |
| 平滑流式 | 关 |
| 流式淡入 | 关 |
| 流式帧率 FPS | 15 |
| 消息加载数 | 手机 20 / 桌面 50 |

- **首次开启前**会把你当前这几项拍成快照存进 App 私有存储。
- 如果你原来某项已经设得比预设更省（例如消息加载数已是 10），一键模式**不会往回抬**。
- 出现「**还原到改动前快照**」按钮后，随时点它把设置原样写回开启前的样子——不会丢你原来的偏好。

**什么时候用**：滚动/打字卡、手机发烫、长聊天打开慢——先无脑点「开启性能模式」，不满意再还原或去下面手动微调。

---

## 二、手动微调（逐项含义 + 何时调）

想自己拿捏的话，展开「手动微调」。每项都能单独开关，**首次改动任意一项时也会先补一份快照**，同样可一键还原。

### No Blur（关背景模糊）
- **含义**：关闭聊天框、弹窗背后的毛玻璃模糊效果。
- **影响**：模糊非常吃 GPU，几乎所有卡顿场景都建议开启此项（= 关模糊）。官方公认最有效的提速项之一。
- **何时调**：任何卡顿场景，第一个就开。介意视觉、机器够强可保留模糊。

### 减少动画
- **含义**：关闭界面过渡动画（展开、淡入等）。
- **影响**：低端机、长聊天滚动更顺。
- **何时调**：滚动或切换界面时掉帧就开。**改此项需刷新页面才完全生效**（管家会即时先关掉一部分，彻底生效请刷新）。

### 关闭阴影
- **含义**：去掉界面元素的投影。
- **影响**：减少重绘，滚动更顺；视觉略扁平。
- **何时调**：追求性能可开；喜欢层次感可留。

### 平滑流式
- **含义**：AI 回复逐字平滑吐字的动画。
- **影响**：好看，但出字过程持续占用渲染。
- **何时调**：出字卡顿、掉帧就关。

### 流式淡入
- **含义**：新出现的文字带淡入效果。
- **影响**：额外渲染开销。
- **何时调**：卡顿时关；不卡可留着好看。

### 流式帧率 FPS（范围 5–100）
- **含义**：AI 回复刷新的帧率，越高越顺滑也越吃性能。
- **默认**：约 30。
- **何时调**：手机 / 低端机官方建议降到 **10–15**，肉眼几乎无差却明显省电省算力。机器强、要极致顺滑可往上调。

### 消息加载数（范围 0–100000，0 = 全部）
- **含义**：打开一个对话时，一次性载入页面的**最近消息条数**。
- **影响**：这是**长聊天最主要的卡顿来源**——载入的消息越多，DOM 越重。
- **何时调**：手机建议 **15–20**、桌面 **50** 左右。往上翻页会继续加载更早的消息，**历史不会丢**。改完管家会**自动重载当前对话**让它立刻生效，无需刷新页面。

## 三、体检

展开「体检」看几项健康度：

- **已禁用扩展数**：仅供参考。
- **Quick Reply 集合数**：全局 QR 集合过多在部分版本会导致输入框拖拽卡顿；卡就精简集合。
- **输入卡顿排查**：ST 里输入卡顿**最常见的元凶是第三方扩展**。逐个禁用扩展定位是哪一个——注意**扩展的启停要刷新页面才真正生效**。

## 四、优化指南（管家改不了、需你手动做的）

这些不在 ST 前端设置范围内，管家只能给建议：

**浏览器**
- **硬件加速是两面刃**：本机同时在跑本地模型（Stable Diffusion / 本地 LLM）时建议**关**硬件加速，把 GPU 让给模型；不跑本地模型则建议**开**。
- **Android 浏览器不要**手动开 GPU rasterization 类实验开关（反而更卡）。
- 桌面 Chrome 可在 `chrome://flags` 试 GPU rasterization / ANGLE D3D11 等（实验项名称随 Chrome 版本变化，搜不到说明已改名或移除）。
- 已知拖慢 ST 的浏览器扩展：iCloud 密码、DeepL、AI 语法纠正类、部分广告拦截器——卡时逐个停用排查。

**服务端 `config.yaml`（前端改不了，需改配置并重启）**
- `requestCompression`：开启后长聊天 + 弱网明显省流量。
- `lazyLoadCharacters`：1.18 默认已开；从旧版本沿用配置的老用户可能仍是 `false`，角色卡多时务必打开。
- `memoryCacheCapacity`：约每 3000 张角色卡增加 100MB。
- `useDiskCache`：仅磁盘极慢（如老 SD 卡）的场景才考虑关。

## 五、生效与还原原理（给好奇的人）

- **流式 / 声音类**改完即时生效。
- **视觉类**（No Blur / 阴影）改后管家会调用 ST 官方的 `applyPowerUserSettings()` 立刻生效。
- **减少动画**部分即时生效，完全生效需刷新页面。
- **消息加载数**改后管家自动重载当前对话。
- **还原** = 把开启前的快照原样写回 + 重跑上述生效动作。

在 st-stage 的网页模拟器（非真实 ST）里打开管家，会因为没有 ST 运行时而**降级为只读的优化指南**，各开关不可用——这是正常的，请到真实 SillyTavern 里使用。
