# 管家使用说明

打开百工手机 →「管家」。当前入口是环境体检：先看检查发现和拟修改项，再应用建议；每次修改记录原值、目标值和实际回读结果，供比较或恢复。

## 检查与应用

1. 打开时自动执行基础检查，显示设备、性能设置能力、禁用扩展数和历史记录。
2. 需要观察运行表现时，选择“不操作时检查”或“滚动长聊天检查”，点击“开始 6 秒体检”。后者自动滚动一小段后恢复位置；切后台、生成回复、切换聊天或手动操作会取消本轮。
3. 阅读“检查发现”和“可以立即应用的建议”。确认后点击“立即应用 N 项建议”；没有完整设置接口的环境只提供只读体检。
4. 有有效恢复记录时，可“再测一次，比较优化前后”或“恢复本次性能设置”。检查条件不同会显示原因，不强算差值。设置是否需要刷新或重载，以每项结果提示为准。

建议涉及酒馆的背景模糊、动画、阴影、流式效果、流式帧率和聊天加载数；不更换模型、改提示词或编辑聊天内容。已经更省资源的设置不会仅为凑齐预设而调高。这里的检查结果不能代替相同设备、聊天和生成状态下的实际使用比较。

## 恢复记录与异常

有效记录按字段保存恢复依据。恢复时以回读结果为准；如果你在别处改过设置，应查看冲突提示并核对，不能把旧快照当作当前状态。

如果保存的性能恢复记录损坏，首页会持续显示“无法恢复上次性能设置”的提示。加载损坏记录本身不会改动酒馆设置，但无法据此恢复旧值，需要你对照自己的备份或酒馆设置核对。点击“我已检查，清除此提示”只删除提示；刷新后也不会再显示，且不会还原或修改设置。

旧扩展排查记录损坏时会提示检查“扩展指南”中的独立恢复备份或手动核对扩展启用状态。旧排查仍未结束且记录有效时保留恢复入口。当前没有发起新的二分禁用实验的界面；底层兼容恢复逻辑遇到零个/一个候选也会停下，保留原备份供恢复。

## 其他入口

- “查看详细结果”：查看检查和操作记录。
- “扩展指南”：了解已安装扩展及注意事项，处理旧排查遗留的恢复状态。
- “记忆与服务器设置建议”：提供需要你自行判断和调整的建议，不自动修改服务端配置。

网页模拟器缺少真实酒馆能力时会降级。实体手机、系统输入法与读屏体验的统一验证步骤见 [统一验收](maintenance/UNIFIED-ACCEPTANCE.md)；当前构建和已验收范围见 [项目状态](maintenance/CURRENT.md)。
