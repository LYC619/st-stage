# 微信：平行世界会话

微信打开后先显示会话列表，并自动加入当前酒馆角色的微信会话。例如从角色卡 A 进入，就能直接在列表找到 A；已有会话会保留，不重复创建或重置记录。未选择角色时不会创建占位联系人。点击右上角「新会话」还可以选择其他角色；即使酒馆主聊天正在和 A 对话，也能在微信里联系 B。选择联系人不会切换酒馆角色。联系人按角色卡头像文件身份区分，同名角色不会合并；头像身份变更后视为新联系人。

新会话只使用该联系人的角色卡快照、此微信会话历史和微信设置，不读取主聊天内容或 MVU 变量。重新从「新会话」选择已添加的角色会刷新角色卡快照并打开原微信会话。旧版按主聊天隔离的记录仍在列表中显示为「旧会话」，不会混入新联系人会话。

## 聊天与状态

每个会话保存自己的草稿、未读数、记录和状态。回复生成时可切到其他联系人；回复会写回原会话并标记未读。每位联系人同时只生成一轮回复。离开微信、清空会话或请求超时后，迟到回复不会再次写入。

请求超过 60 秒会显示超时原因，保留已发送消息。生成中可取消，失败或取消后可重试；重试复用原消息，不重复添加玩家发言，也不清空后续草稿。刷新后保留失败信息，未完成的旧请求显示为已中断。已配置 AI 时，网络、HTTP 和回复格式错误会明确显示，不替换成固定本地回复。

## 群聊、朋友圈与语音

「建群」可选 2–50 位角色，保存群名；「群成员」可调整成员，头像最多显示九格。普通消息依次请求所有成员，使用各自角色卡和状态，并显示发言人姓名。通过下拉选择 @ 可按稳定身份唤醒同名角色中的指定成员；输入 `@名字` 也可定向，`@所有人`/`@all` 唤醒全群。单轮群回复在全部成功后统一入历史，某个成员失败时不会保存半轮回复，可重试或取消。群聊不切换酒馆主角色、不读取主聊天或 MVU。

「朋友圈」选择角色后生成文字和可选图片，使用角色卡及最近微信状态；可编辑、保存、恢复动态提示词。图片只能引用该角色启用的素材，动态保留发送时快照。点赞和最近 200 条动态保存在本地设置中。无 Key 时明确标记为本地演示；生成可取消，超时或失败可再次生成。关闭窗口会取消未完成的生成。

「语音消息」将输入的文字发送为语音气泡，AI 也可用 `{"type":"voice","content":"朗读内容"}` 回复。点击播放才调用酒馆已启用的 TTS，文字原样传递并立即展开转写。酒馆接口返回不代表已经播放，界面会说明播放状态无法确认；未启用、失败或 15 秒无响应时可阅读文字并重试。新回复到达后保留既有语音的展开状态和键盘焦点。此功能不录音、不识别麦克风，也不保存音频文件。

「内心想法」「当前状态」和可选的 0–100 心情值由 AI 在同一次回复 JSON 中返回并自动保存。状态栏默认收起，点击可展开内心独白。缺失或无效状态不会清空旧值。朋友圈按该角色实际状态更新时间选择最近状态，生成和保存使用同一快照；其他群成员发言不会刷新该角色的状态时间。钱包、模拟天数、每日生活费和第二次数值评估已退出新工作流；旧数值只作为历史兼容数据保留，不扣减、不回写 MVU。

红包可以填写任意内容，例如「一杯奶茶」「520 元」「一张船票」，也可附留言。它是角色互动中的虚构礼物，不执行支付。发送前要点击明确的「发送红包」按钮。

## 设置

右上角「⚙ 设置」随时可见。称呼、场景补充和新会话开场白直接展示并可编辑；提示词、素材、模板、连接和记录操作按用途收起。保存结果在面板底部持续显示，保存后可继续编辑。关闭面板会丢弃尚未保存的表单修改。

- **通用设置**：所有没有专用设置的联系人共用。
- **此联系人专用设置**：只影响此联系人；首次保存时建立独立副本。
- 已有专用设置的联系人可以点击「此联系人改用通用设置」，再保存解除覆盖。单独编辑通用设置不会暗中删除专用设置。

编辑目标会记住到下次打开。设置变化从下一条发送开始生效；在途请求继续使用发送时的配置快照。开场白只用于新会话，不重写旧消息。模板默认收起，预览套用和导入只修改表单，保存设置后才用于聊天。模板最多 30 个、JSON 最多 64 KB，仅含配置、提示词和素材引用，不含 API Key、记录或角色状态。

## 提示词

聊天提示词、状态提示词、输出格式提示词全部明文显示，可独立编辑与恢复默认。「预览实际发送的提示词」使用当前表单和联系人生成系统提示词预览；微信历史在发送时另行附加。动态占位符包括 `{角色}`、`{人设}`、`{用户}`、`{称呼}`、`{场景}`、`{时间}`、`{状态}`、`{表情}`、`{图片}`、`{背景}`。独立会话不填入主聊天背景。

默认格式为：

```json
{
  "messages": [{ "type": "text", "content": "回复内容" }],
  "inner_thought": "虚构角色未说出口的想法",
  "current_status": "正在整理行李",
  "mood": 82
}
```

`messages` 最多接收 4 条；表情用 `emoji_id`，图片用 `pic_id`，仅接受启用素材列表中的 ID。状态只接受有界非空字符串，不执行模型返回的代码或 HTML。

## 表情与图库

默认可见「我的表情」「联系人表情」两组；新通用配置默认不启用旧版专属照片；已有旧场景配置保留其分组选择。已有明确关闭素材的设置保留关闭状态，抽屉会显示原因和「管理」入口。

素材管理可以逐组预览，修改图片地址、显示名和含义说明，也能恢复原始素材。通过「从图库选择图片」添加已有图库图片，选择放入我的表情、联系人表情或联系人图片。支持 HTTPS 和酒馆 `/user/images/` 地址；内嵌图片需先在图库保存到酒馆。最多添加 100 张，模板保存图片引用，不携带图片文件。

新发送的素材保存当时的图片和含义快照，后续修改、移除或禁用素材组不破坏历史显示；旧消息仍兼容内置 ID。远程图片可用性取决于原服务。

## 连接与验证边界

AI 连接在所有微信联系人中共用，使用兼容 OpenAI Chat Completions 的完整端点。它仍独立于酒馆主聊天连接；不自动读取酒馆日常密钥。没有 Key 时明确显示「本地演示模式」，有 Key 的请求失败时保留错误和重试入口。

自动验收使用独立 ST 1.18.0、合成角色与受控 AI 响应，覆盖会话隔离、群聊、朋友圈、语音、失败/取消/超时重试、提示词、素材、保存重载和浏览器手机布局。TTS 验证调用宿主接口，未验证实际音频供应商。真实模型表现、实体设备/系统输入法、完整读屏体验仍需对应环境。当前构建和测试结果以 [共享状态](maintenance/CURRENT.md) 为准。
