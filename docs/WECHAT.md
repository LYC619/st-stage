# 微信：主线记忆与社交动态

微信打开后先显示会话列表，并自动加入当前酒馆角色的微信会话。例如从角色卡 A 进入，就能直接在列表找到 A；已有会话会保留，不重复创建或重置记录。未选择角色时不会创建占位联系人。右上角「+」提供「添加好友」「发起群聊」。底部「微信／通讯录／朋友圈」切换三个完整页面；通讯录列出好友和群聊，进入聊天后返回原来的页面。导航支持方向键、Home/End，菜单支持方向键和 Escape。

酒馆主聊天正在和 A 对话时，也能在微信里联系 B，选择好友不会切换酒馆角色。联系人按角色卡头像文件身份区分，同名角色不会合并；头像身份变更后视为新联系人。通过「添加好友」重新选择已有角色会刷新角色卡快照并打开原会话。旧版按主聊天隔离的记录仍显示为「旧会话」。

## 主线记忆与世界书

默认读取最近 12 条主聊天，作为带人物来源的故事背景注入微信回复和朋友圈；角色卡、微信消息与状态分别保存，不读取或回写 MVU。设置中的「主线记忆与世界书」可调整为 0–20 条，0 表示关闭主聊天背景；世界书有独立开关。旧版隐式的 0 会一次性升级为 12，升级后主动保存的 0 会保留。

世界书来源包含联系人和主线角色卡绑定的书、额外角色绑定、嵌入角色卡的条目、当前聊天绑定及全局启用的书。读取禁用过滤后的常驻和关键词匹配条目，支持次级关键词逻辑、角色文件身份和标签筛选，按顺序去重并限制内容预算。提示词明确区分主线中的人物和当前联系人，避免将他人经历当成亲历。读取失败会提示，并保留可用的背景。

这是独立的有界背景提取：最多读取 12 本外部世界书，世界书文本总预算 10000 字符，单条最多 4000 字符；主线背景最多 16000 字符。关键词采用不区分大小写的普通文本匹配，不复刻酒馆原生扫描器的正则、向量检索、概率、递归、时效及插入位置规则，也不改变原生世界书的计时状态。

## 聊天与状态

每个会话保存自己的草稿、未读数、记录和状态。回复生成时可切到其他微信联系人；回复会写回原会话并标记未读。每位联系人同时只生成一轮回复。切换酒馆主聊天、离开微信、清空会话或请求超时后，迟到回复不会再次写入。

请求超过 60 秒会显示超时原因，保留已发送消息。生成中可取消，失败或取消后可重试；重试复用原消息，不重复添加玩家发言，也不清空后续草稿。刷新后保留失败信息，未完成的旧请求显示为已中断。已配置 AI 时，网络、HTTP 和回复格式错误会明确显示，不替换成固定本地回复。

## 群聊、朋友圈与语音

「+ → 发起群聊」可选 2–50 位角色，保存群名；「群成员」可调整成员。2–4 人使用四宫格头像，更多成员使用九宫格，最多显示九位。普通消息依次请求所有成员，使用各自角色卡和状态，并显示发言人姓名。群聊输入栏上方保留可用键盘操作的 @ 下拉选择器，可按稳定身份唤醒同名角色中的指定成员；输入 `@名字` 也可定向，`@所有人`/`@all` 唤醒全群。单轮群回复在全部成功后统一入历史，某个成员失败时不会保存半轮回复，可重试或取消。群聊按各成员的记忆设置注入背景，不切换酒馆主角色或读写 MVU。

连接 AI 后，进入微信或收到酒馆主线新消息会自动为最多两位活跃角色生成近况，优先当前主线角色，再选最近微信会话中的角色。自动任务在离开微信后仍能随主线运行；相同剧情去重，更新间隔至少两分钟，期间的新消息合并处理。生成使用角色卡、主线与世界书、最近微信状态和已有动态。朋友圈 Tab 直接显示时间线；生成中保留旧动态、点赞、焦点和阅读位置。

角色可偶尔返回 `visibility: "private"`，界面标记「🔒 仅你可见」。这是故事中的可见性标识，数据仍保存在同一份酒馆设置中。设置中的「朋友圈偏好」可关闭自动更新或私密动态，也可手动选择角色生成、编辑和恢复动态提示词。默认提示词要求专属动态符合角色关系，不强制暧昧或编造共同经历。

自动任务不会在未配置 AI 时请求或制造演示动态；手动生成在本地演示模式下仍可试用。每批自动更新最多两次模型请求，使用微信自己的 AI 连接。生成可取消，60 秒超时，失败可点击「刷新近况」重试。切换酒馆主聊天会取消旧任务；关闭设置取消手动生成。图片只能引用启用素材，动态保留发布时快照；点赞和最近 200 条动态保存于酒馆扩展设置。

输入栏左侧的 🎙️ 切换为语音模式，点击「点击录音」使用浏览器语音识别，再次点击可结束。识别结果只填入草稿，编辑确认后点击「发送」或按回车才发送为语音气泡；重新录音会追加到原草稿。不支持识别、权限拒绝或识别失败时仍可输入文字，⌨️ 可切回普通文字消息。切换会话、打开对话框或离开微信会取消录音，迟到结果不会覆盖草稿。扩展只保存文字，不保存录音文件；语音识别可用性取决于浏览器及其识别服务。

AI 也可用 `{"type":"voice","content":"朗读内容"}` 回复。点击语音气泡的播放按钮才调用酒馆已启用的 TTS，文字原样传递并立即展开转写。酒馆接口返回不代表已经播放，界面会说明播放状态无法确认；未启用、失败或 15 秒无响应时可阅读文字并重试。新回复到达后保留既有语音的展开状态和键盘焦点。

「内心想法」「当前状态」和可选的 0–100 心情值由 AI 在同一次回复 JSON 中返回并自动保存。状态栏默认收起，点击可展开内心独白。缺失或无效状态不会清空旧值。朋友圈按该角色实际状态更新时间选择最近状态，生成和保存使用同一快照；其他群成员发言不会刷新该角色的状态时间。钱包、模拟天数、每日生活费和第二次数值评估已退出新工作流；旧数值只作为历史兼容数据保留，不扣减、不回写 MVU。

红包可以填写任意内容，例如「一杯奶茶」「520 元」「一张船票」，也可附留言。它是角色互动中的虚构礼物，不执行支付。发送前要点击明确的「发送红包」按钮。

## 设置

右上角「⚙ 设置」随时可见。AI 连接位于设置顶部，显示当前连接状态；演示提示中的「连接 AI」可直接跳到密钥输入处。称呼、场景补充和新会话开场白直接展示并可编辑；提示词、素材、模板和记录操作按用途收起。保存结果在面板底部持续显示，保存后可继续编辑。关闭面板会丢弃尚未保存的表单修改。

- **通用设置**：所有没有专用设置的联系人共用。
- **此联系人专用设置**：只影响此联系人；首次保存时建立独立副本。
- 已有专用设置的联系人可以点击「此联系人改用通用设置」，再保存解除覆盖。单独编辑通用设置不会暗中删除专用设置。

编辑目标会记住到下次打开。设置变化从下一条发送开始生效；在途请求继续使用发送时的配置快照。开场白只用于新会话，不重写旧消息。模板默认收起，预览套用和导入只修改表单，保存设置后才用于聊天。模板最多 30 个、JSON 最多 64 KB，仅含配置、提示词和素材引用，不含 API Key、记录或角色状态。

## 提示词

聊天提示词、状态提示词、输出格式提示词全部明文显示，可独立编辑与恢复默认。「预览实际发送的提示词」使用当前表单、联系人及启用的记忆生成系统提示词预览；微信历史在发送时另行附加。动态占位符包括 `{角色}`、`{人设}`、`{用户}`、`{称呼}`、`{场景}`、`{时间}`、`{状态}`、`{表情}`、`{图片}`、`{背景}`。即使自定义聊天提示词遗漏 `{背景}`，启用的记忆仍会附加。

默认格式为：

```json
{
  "messages": [{ "type": "text", "content": "回复内容" }],
  "inner_thought": "虚构角色未说出口的想法",
  "current_status": "正在整理行李",
  "mood": 82
}
```

`messages` 最多接收 4 条；表情用 `emoji_id`，图片用 `pic_id`，仅接受启用素材列表中的 ID。状态只接受有界非空字符串，不执行模型返回的代码或 HTML。

## 表情与图库

默认可见「我的表情」「联系人表情」两组；新通用配置默认不启用旧版专属照片；已有旧场景配置保留其分组选择。已有明确关闭素材的设置保留关闭状态，抽屉会显示原因和「管理」入口。

素材管理可以逐组预览，修改图片地址、显示名和含义说明，也能恢复原始素材。通过「从图库选择图片」添加已有图库图片，选择放入我的表情、联系人表情或联系人图片。支持 HTTPS 和酒馆 `/user/images/` 地址；内嵌图片需先在图库保存到酒馆。最多添加 100 张，模板保存图片引用，不携带图片文件。

素材区在展开时加载图库，折叠再展开保留当前尚未保存的编辑。新发送的素材保存当时的图片和含义快照，后续修改、移除或禁用素材组不破坏历史显示；旧消息仍兼容内置 ID。远程图片可用性取决于原服务。

## 连接与验证边界

AI 连接在所有微信联系人中共用，使用兼容 OpenAI Chat Completions 的完整端点。它仍独立于酒馆主聊天连接；不自动读取酒馆日常密钥。没有 Key 时明确显示「本地演示模式」，有 Key 的请求失败时保留错误和重试入口。

自动验收使用独立 ST 1.18.0、合成角色与受控 AI 响应，覆盖会话隔离、群聊、朋友圈、语音、失败/取消/超时重试、提示词、素材、保存重载和浏览器手机布局。录音交互使用受控浏览器识别事件验证，未测试实际麦克风或识别服务。TTS 验证调用宿主接口，未验证实际音频供应商。真实模型表现、实体设备/系统输入法、完整读屏体验仍需对应环境。当前构建和测试结果以 [共享状态](maintenance/CURRENT.md) 为准。
